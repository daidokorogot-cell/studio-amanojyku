# STUDIO AMANOJAKU サイト

スマホ向けの1ページサイトです。`index.html` と `images/` フォルダだけで動きます(ビルド不要)。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作る(例: `studio-amanojaku-site`、Public)
2. このフォルダの中身(`index.html`・`images/`・`README.md`)をそのままアップロード
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/studio-amanojaku-site/` で公開される

更新するときは `index.html` を差し替えてコミットすれば自動で反映されます。
